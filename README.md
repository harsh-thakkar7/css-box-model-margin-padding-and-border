# CSS Box Model — Margin, Padding and Border

A hands-on exercise demonstrating the CSS box model through margin, padding, and border.

## Concepts Shown

- **Padding** — spacing inside an element (`#first` box)
- **Border** — visible edges with customizable widths (`#second` uses asymmetric `20px 10px`)
- **Margin** — spacing outside an element (shifts the second and third boxes)

Three colored `div` boxes (`cadetblue`, `gold`, `indianred`) are laid out with different padding, border, and margin values so you can visually inspect the box model.

## Viewing

Open `index.html` in any web browser.
